# Cassette J Card Studio

[日本語](README.md) | [English](README.en.md)

カセットテープのJカード（ケースの紙ジャケット）を作成する、HTML単体のアプリです。画像処理はすべてブラウザー内で行われ、インストールは不要です。

## 起動方法

[https://eiraruinveil.github.io/Cassette-J-Card-Studio/](https://eiraruinveil.github.io/Cassette-J-Card-Studio/)
を開いてください。HTMLファイル1つで動作するアプリで、画像処理はブラウザー内で行われます。画面右上のボタンで日本語と英語を切り替えられます（設定は保存されます）。

リポジトリ：[https://github.com/EiraRuinveil/Cassette-J-Card-Studio](https://github.com/EiraRuinveil/Cassette-J-Card-Studio)

## テンプレート（型）

ツールバーの「型」で、2種類のJカードから選べます。どちらも300 DPIです。

| 型 | 全体サイズ | 裏表紙フラップ | 背 | メイン（表紙） |
| --- | --- | --- | --- | --- |
| ショートフラップ型 | 1053 × 1218 px（89.2 × 103.1 mm） | 177 px（15.0 mm） | 153 px（13.0 mm） | 723 px（61.2 mm） |
| ロングフラップ型 | 1219 × 1200 px（103.2 × 101.6 mm） | 300 px（25.4 mm） | 150 px（12.7 mm） | 769 px（65.1 mm） |

- ショートフラップ型は、フラップがケースの狭い部分にちょうど収まるタイプです。フラップはカードを留める役目が中心です。
- ロングフラップ型は一般的なJカードで、フラップに曲目リストなどを印刷できます。
- おもて面とうら面は同じ紙の表裏です。並びは、おもて面が「フラップ｜背｜メイン」、うら面が「メイン｜背｜フラップ」で、折ると背どうし・フラップどうしが重なります。
- 型を切り替えると、デザインはそのまま引き継がれ、文字・画像レイヤーの位置は比率に合わせて拡縮されます。選んだ型はブラウザーとプロジェクトファイルに保存されます。

### テンプレートファイル

各部位の名前が入ったテンプレートを用意しています。テスト印刷などにお使いください。
アプリのカード5「テンプレート読込」ボタンから直接読み込むこともできます。下記のファイルをダウンロードし、「プロジェクト読込」から開くこともできます。

## 操作

### パネル（部位）

- 部位は「表紙／裏面メイン」「背」「裏表紙フラップ」で、おもて面・うら面それぞれにあります。
- 部位ごとに背景色と画像を設定できます。画像はフィット方法（全体を表示／埋める／引き伸ばし）、大きさ、回転を指定でき、プレビュー上でドラッグして位置を動かせます。
- カード1の「この部位に文字を追加」に打ち込むと、選んでいる部位の中央に文字が入ります（Enterで改行、「追加」ボタンか Ctrl+Enter で追加）。プレビューのダブルクリックでも部位を選んで文字入力に移れます。

### 背（Spine）

- タイトル、アーティスト名、カタログ番号を入力できます。
- タイトル／アーティスト／カタログ番号は、それぞれ文字サイズ・フォント・位置を個別に調整できます（色は背全体で共通）。向きは回転（左読み／右読み）の2種類です。
- アーティストとタイトルは1行に並べて背の中央に表示されます。字間（文字の間隔）も調整できます。
- 背の文字はプレビュー上で直接ドラッグしても動かせます（上下方向のみ、横は常に中央）。選択中は ↑↓ キーでも動かせます。
- 「背部分を塗りつぶす」で、背の背景に色を重ねられます（おもて／うら両方の背に適用、文字はその上に描かれます）。背自体の背景色は、パネル選択で「背」を選んで変更してください。

### レイヤー（文字・画像・フォント）

- 文字レイヤー：複数行、縦書き（文字を縦に積む）、回転、字間、色、太さ、フォントを個別に設定できます。
- 画像レイヤー：自由な位置に画像を置けます。大きさ、回転、透明度、重なり順を調整できます。
- フォントファイル（TTF / OTF / WOFF / WOFF2）を読み込むと、背・文字レイヤー・曲目リストで使えます。読み込んだフォントはプロジェクトファイルにも保存されます。
- レイヤーはプレビュー上でドラッグして移動でき、クリックで選択できます。Shift＋ドラッグで縦横まっすぐに移動、矢印キーで1px（Shift＋矢印で10px）ずらせます。
- スライダーの数値表示をクリックすると、数値を直接入力できます（Enterで確定、Escで取消）。

### 曲目リスト

- 表示する場所は「うら面メイン」「裏表紙フラップ（うら）」「裏表紙フラップ（おもて）」から選べます。
- 文字サイズ、字間、色、フォント、回転（−180〜180°）を設定できます。フラップに置くときは文字サイズを小さめにすると収まります。回転を90°にするとフラップの縦方向に沿って読めます。
- 文字を入力すると自動で表示ONになり、プレビューが置く場所の面に切り替わります。

### その他

- 「両面プレビュー」で、おもて面とうら面を並べて確認できます。
- プレビューのズームは「画面に合わせる」かスライダーで調整できます。

## 書き出し

「書き出し」ボタンのダイアログで、形式と内容を選んで書き出します。選択を変えると、書き出しレイアウトのプレビューが自動で表示されます。

- **形式**：PDF／PNG／JPG／印刷
- **出力内容**：カード実寸（おもて面／うら面／両面）／A4（おもて面／うら面／両面）
- A4では同じデザインを1ページに2個並べることもできます。切り取りガイド（点線）は色反転で描かれるため、黒いデザインでは白く、白いデザインでは黒く見えます（表示／非表示を選べます）。
- 「折り線（パネルの境目）」を「入れる」にすると、パネルの境目に色反転の点線が書き出し・印刷にも入ります（プレビューにも表示されます）。設定は保存されます。
- ファイル名には寸法が入ります（例：`jcard_front_1053x1218_300dpi.png`）。寸法は選んでいる型によって変わります。

## プロジェクトの保存

「プロジェクト保存」で、画像、文字、設定、読み込んだフォント、選んでいる型をJSONファイル1つにまとめます。次回は「プロジェクト読込」から一括で復元できます。

## 印刷について

- 家庭用プリンターでは、印刷倍率を「実際のサイズ」または100%にしてください。ブラウザー印刷では0.5mmほど大きく出ることがあるため、サイズ補正の初期値は −0.5mm にしてあります。実寸とずれるときは「サイズ補正（mm）」で調整してください。
- 印刷業者へ入稿する場合は、各業者のデータ作成ガイドを確認してください。
- プリンター、アプリ、PDF閲覧ソフト、業者の設定や仕様によって実寸印刷ができない場合があります。印刷結果について、アプリの提供者は責任を負いません。
